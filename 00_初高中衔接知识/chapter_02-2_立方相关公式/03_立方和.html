立方和公式：因式分解与几何解析

本节先从代数运算推出 a3+b3 的标准分解式，再用立方体的体积重排解释这个公式。

a3+b3 表示两个完整立方相加。目标是把它写成乘积形式。

01公式推导

1. 公式推导：从一次因子到分解式

立方和要分解的是 a3+b3。如果 b=-a，那么原式为 0；而 b=-a 等价于 a+b=0。这提示我们可以先尝试一次因子 a+b，再通过乘回去检查，确定剩下的二次因子。

a3+b3 = (a+b)(a2 + kab + b2)

先尝试一次因子 a+b。剩下的应是二次式：首项用 a2 才能乘出 a3，末项用 b2 才能乘出 b3，未知的中间项先写成 kab。

(a+b)(a2 + kab + b2)

接下来检查这个候选分解是否真的能乘回 a3+b3，所以要把右边完整乘开。

= a3 + ka2b + ab2 + a2b + kab2 + b3

这里使用乘法分配律：a 和 b 分别去乘二次因子的三项，于是出现六个乘积项。

= a3 + (k+1)a2b + (k+1)ab2 + b3

把同类混合项合并：ka2b+a2b 合成 (k+1)a2b，ab2+kab2 合成 (k+1)ab2。

k + 1 = 0，所以 k = -1

左边原式只有 a3 和 b3，没有 a2b 和 ab2。因此混合项系数必须为 0。

a3+b3 = (a+b)(a2 - ab + b2)

把 k=-1 代回二次因子，就得到立方和分解公式。中间的 -ab 正是为了抵消乘回去时出现的两类混合项。

通过以上代数运算，可以得到立方和的分解式。二次因子里的 -ab 不是硬背出来的，而是为了让乘回去时出现的两类混合项正好抵消。
02几何解析

2. 几何解析：切割重排看见共同高度

立方和可以看作一个体积重排问题。为了便于观察，先按 b>a 来看：把边长为 a 的小立方体放在边长为 b 的大立方体上方角落。下面每一步只看一个动作：从两个立方体出发，切下一块，搬到上方，再把重排后的高度和底面积写出来。

1两个立方

从两个完整立方体出发

原来的对象不是一个整体立方，而是两个完整立方体的体积相加。先把 a3 放到 b3 的上方角落，准备观察它们怎样重排。

a3+b3
2切下一块

从 b3 中切下一块长方体

这块长方体的三条边可以看成 a、b、b-a，所以体积是 ab(b-a)。切下它不是删除，而是为了后面搬动。

切块体积 = ab(b-a)
3搬到上方

把切下的长方体搬到剩余立体的上方

搬动只改变位置，不改变体积。重排以后，上面补出高度 a，下面原来有高度 b，合起来就是共同高度 a+b。

共同高度 = a+b
4共同高度

用共同高度和底面积写成乘积

重排后的新立体整体高度是 a+b。底面由一个正方形底面 a2 和一条长方形底面 b(b-a) 组成，所以可以先写成乘积，再把底面积化简成二次因子。

a3+b3 = (a+b)[a2+b(b-a)] a2+b(b-a) = a2-ab+b2 a3+b3 = (a+b)(a2-ab+b2)

这个几何看法不是替代前面的代数推导，而是帮助你看见公式里的两个因子分别对应什么：a+b 是重排后的共同高度，a2-ab+b2 是重排后的底面积。

03核心结论

3. 核心结论

立方和的分解公式是：

a3 + b3 = (a+b)(a2 - ab + b2)

一次因子 a+b 来自“当 a+b=0 时原式为 0”；二次因子里的 -ab 来自“乘回去时混合项必须抵消”，也可以从重排后底面积 a2-ab+b2 中看见。
