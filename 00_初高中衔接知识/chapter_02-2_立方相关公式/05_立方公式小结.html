02-2 立方相关公式 · 05

立方公式小结：先判断对象，再决定变形

立方相关公式容易混淆，关键在于先看清式子的对象。

看到三次方时，先问一句：这是一个整体被立方，还是两个完整立方在相加或相减？

00对象判断
看到的式子它在说什么变形方向
(a+b)3一个和整体被立方展开
(a-b)3一个差整体被立方展开
a3+b3两个完整立方相加因式分解
a3-b3两个完整立方相减因式分解
01展开

1. 整体被立方时，要把乘法展开

(a+b)3 的意思是三个相同因式相乘：

(a+b)3 = (a+b)(a+b)(a+b)

所以和的立方要做的是展开。先乘开，再合并同类项：

(a+b)3 = a3+3a2b+3ab2+b3

(a-b)3 也是一样，只是每个因式里都有 -b：

(a-b)3 = (a-b)(a-b)(a-b)

乘开以后，符号由 -b 出现的次数决定：

(a-b)3 = a3-3a2b+3ab2-b3

这一类公式的核心是：从乘积出发，展开成多项式。

02分解

2. 两个立方相加或相减时，要写成乘积

a3+b3 和 a3-b3 已经是两个立方项放在一起。这里要做的是因式分解，把三次式写成因子相乘。

立方和写成：

a3+b3 = (a+b)(a2-ab+b2)

立方差写成：

a3-b3 = (a-b)(a2+ab+b2)

为什么要写成乘积？因为乘积形式能把隐藏的因子看出来。

比如解方程：

x3-8 = 0

写成：

x3-23 = 0

再分解：

(x-2)(x2+2x+4) = 0

这时就能先看见：

x-2 = 0

所以：

x = 2

乘积形式的作用是让我们能使用“乘积为 0”这个结构。它也能帮助约分、化简和继续分解。单看 a3+b3 或 a3-b3，这些因子关系不明显；写成乘积后，一次因子和二次因子就分开了。

03一次因子

3. 为什么能先找 a+b 或 a-b

找一次因子时，先看原式什么时候会变成 0。

对立方差：

a3-b3

当 a=b 时：

a3-b3 = 0

而 a=b 可以写成：

a-b = 0

这说明 a3-b3 里有一个很自然的候选因子：

a-b

对立方和：

a3+b3

当 b=-a 时：

a3+b3 = a3+(-a)3 = 0

而 b=-a 可以写成：

a+b = 0

这说明 a3+b3 里有一个很自然的候选因子：

a+b

这就是因式定理的简单用法：如果一个式子在某个一次式等于 0 时也变成 0，这个一次式就可以作为因子候选。候选因子找到以后，还要乘回去检查。

04二次因子

4. 二次因子怎样确定

一次因子确定后，剩下的因子应该是二次式。

先看立方和：

a3+b3 = (a+b)(a2+kab+b2)

这里 a2 用来和前面的 a 乘出 a3，b2 用来和前面的 b 乘出 b3。中间项先写成 kab。

乘开右边：

(a+b)(a2+kab+b2) = a3+(k+1)a2b+(k+1)ab2+b3

左边 a3+b3 没有 a2b 和 ab2，所以：

k+1 = 0

于是：

k = -1

得到：

a3+b3 = (a+b)(a2-ab+b2)

再看立方差：

a3-b3 = (a-b)(a2+kab+b2)

乘开右边：

(a-b)(a2+kab+b2) = a3+(k-1)a2b+(1-k)ab2-b3

左边 a3-b3 没有 a2b 和 ab2，所以：

k-1 = 0

于是：

k = 1

得到：

a3-b3 = (a-b)(a2+ab+b2)

二次因子的中间项由乘回去时的混合项抵消决定。

05判断顺序

5. 最后按这个顺序判断

看到立方相关式子时，可以这样判断：

1. 先判断：一个整体被立方吗？ (a+b)^3 或 (a-b)^3 -> 展开。 2. 再判断：两个完整立方相加吗？ a^3+b^3 -> 找 a+b，再确定二次因子。 3. 再判断：两个完整立方相减吗？ a^3-b^3 -> 找 a-b，再确定二次因子。 4. 最后乘回去检查。

最后真正要记住的是：先判断对象，再决定展开还是分解；分解时先找让原式变成 0 的一次因子，再用乘回去确定二次因子。
