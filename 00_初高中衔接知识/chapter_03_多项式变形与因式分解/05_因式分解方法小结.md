# 因式分解方法小结：按结构选择方法

前面几篇分别处理了不同的多项式结构。面对一个新式子时，先做固定检查，再根据剩余结构选择方法；每得到一个新因式，都要重新检查并在最后乘回原式。

## 1. 先做两项固定检查

面对一个新的多项式，先后顺序可以保持不变：

1. **先提公因式。**检查每一项共同含有的数字、字母或整式，并把公因式完整提出。
2. **再查完整公式。**核对项数、指数、系数和符号；完整符合已学公式时，直接使用相应公式分解。

这两项检查会降低式子的复杂程度，也能让后面的结构更容易显现。完成这两步以后，剩余多项式的结构决定下一步使用哪种方法。

## 2. 按剩余结构选择方法

固定检查完成后，先看剩余部分属于哪一类结构：

| 剩余结构 | 选择的方法 | 何时停止或换方法 |
| --- | --- | --- |
| 局部项提出公因式后能产生同一完整括号 | 分组分解 | 几种自然分组都无法统一括号时，换用其他方法 |
| 二次三项式的整数因数配对较少 | 十字相乘 | 配对明显增多或全部失败时，及时停止试配 |
| 剩余式是一元二次多项式，且配对较多、全部失败或需要判断实数范围 | 判别式与求根公式 | 从 $a,b,c$ 出发判断实数根，再由根写出一次因式 |
| 同一个整式反复出现 | 先整体代换，再按替换后的结构判断 | 换回原来的整式后，继续检查所得因式 |
| 不符合以上结构 | 本章方法不能直接处理 | 保留当前结果，不能只根据试配或分组失败断言它无法继续分解 |

选定方法只完成当前一层分解。得到新因式以后，检查需要从头开始。

## 3. 每得到新因式都重新检查

一次变形可能只显现部分乘积结构。把每个新因式当作新的检查对象，才能判断它是否还能继续分解。

这条重复路径可以写成：

$$
\text{得到新因式}
\longrightarrow
\text{重查公因式与公式}
\longrightarrow
\text{按结构再选方法}.
$$

只要某个新因式仍能继续分解，就对它重复这条路径。当所有非常数因式在指定系数范围内都不能继续分解时，检查才停止。因此，最后还要明确允许的系数范围，并乘回原式检查。

## 4. 明确范围，再乘回检查

说一个多项式“不能再分解”时，需要同时说明允许的系数范围。

- **整数或有理数范围：**十字相乘主要寻找这些范围内的一次因式。整数配对失败后，还要根据当前目标判断是否需要扩展到实数。
- **实数范围：**对于二次三项式，$\Delta<0$ 时没有实系数一次因式；$\Delta\ge0$ 时可以由实数根写出一次因式。
- **乘回原式：**将所有因式展开，确认项数、次数、系数和符号全部恢复。

完整的因式分解路径是：先提公因式，再查完整公式；按剩余结构选择方法，对新因式重新检查；达到指定系数范围内的停止位置后，乘回原式确认结果。

本章得到的因式结构会继续用于下一章的分式约分与式子化简。进入分式和根式以后，还要同时保留原式的成立条件。
