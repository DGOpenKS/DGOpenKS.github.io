# 分式、根式与条件控制

整式变形主要关心怎样展开、合并和因式分解。进入分式和根式以后，表达式还会主动排除某些取值：分母不能为 $0$，二次根式的被开方数不能为负，根式位于分母时还必须保证整个分母非零。

因此，本章始终同时研究两件事：表达式怎样变形，以及它允许哪些值进入。式子的外形可以改变，原式产生的条件不能在变形中消失。

```text
代数表达式对象 = 表达式形式 + 允许范围
```

## 本章的核心内容

进入分式和根式以后，代数变形不仅要看式子的外形，还必须同时追踪表达式允许的取值。

学完本章，面对一个分式、根式或复合表达式，应当能够：

1. 找出表达式产生的全部成立条件；
2. 根据结构选择合法的化简或运算规则；
3. 说明规则为什么成立以及需要什么条件；
4. 判断变形是否保持了原式允许范围；
5. 在最终结果中同时给出化简形式和原式条件。

## 七节怎样连接起来

本章分成三条连续的学习线。

### 分式线

分式第一次让我们清楚看见：一个表达式不仅有外形，还有分母产生的禁点。

### 根式线

根式带来另一种边界：被开方数和算术平方根都受到非负性控制。理解这种边界以后，才能正确化简、运算、进行分母有理化，并把根式写进指数语言。

| 顺序 | 内容 | 本节核心 |
| --- | --- | --- |
| [03 二次根式的意义与化简](03_二次根式的意义与化简.md) | 算术平方根、非负性、平方因子、绝对值、最简根式 | 非负性控制根式的意义和化简 |
| [04 根式的四则运算](04_根式的四则运算.md) | 根式乘除、同类根式、分配律和乘法公式 | 乘除结构与加减结构使用不同规则 |
| [05 分母有理化](05_分母有理化.md) | 乘以 $1$、单根式分母、共轭式、平方差 | 改变根式分母并保持原式的值 |
| [06 根式与分数指数幂](06_根式与分数指数幂.md) | 根式与有理指数的对应、负分数指数、底数范围 | 把开方写进统一的指数语言 |

第 06 节是本章通向高中指数内容的衔接扩展。它仍然遵守本章主线：符号语言改变以后，定义范围不能消失。

### 综合线

最后把分式、根式、嵌套层级和可能约去的因子放在同一个对象中，建立完整的条件检查链。

| 顺序 | 内容 | 本节核心 |
| --- | --- | --- |
| [07 复合条件与等价化简](07_复合条件与等价化简.md) | 从内向外检查根式、检查完整分母、取条件交集、保留被隐藏的条件 | 找全复合条件并保持等价化简的范围 |

整章的学习顺序可以概括为：

```text
分式让我们看见禁点
→ 分式运算要求持续保留禁点
→ 根式让我们看见非负边界
→ 根式运算要求按结构选择规则
→ 有理化展示怎样用等值依据改变形式
→ 分数指数展示换一种符号语言仍要保留范围
→ 复合条件把所有限制放进同一条检查链
```

## 本章与前后内容的边界

第三章的因式分解、平方差和乘法公式，是本章约分、通分、根式运算与共轭有理化的重要工具。本章使用这些结构，但不重复完整推导。

本章研究的是表达式的意义、运算、化简和成立条件，不讨论分式方程、根式方程、不等式求解或验根。下一章会继续研究：当表达式进入方程和不等式以后，变形怎样影响候选结果和最终解集。

本章最后要形成的稳定判断是：先确认对象在哪些值上成立，再在这个范围内选择合法变形；写出结果时，化简形式和原式条件缺一不可。
