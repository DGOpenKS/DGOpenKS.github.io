# 方程、不等式与约束

第四章研究的是表达式什么时候有意义、怎样运算以及怎样保留原式条件。进入方程和不等式以后，我们还要继续追问：变形前后是否有相同的解，最后得到的值或区间是否满足原来的限制。

本章围绕一个核心差别展开：

```text
方程乘除变形：先确定乘除式不为零
不等式乘除变形：不仅要确定它不为零，还要知道它是正还是负
```

这个差别会依次解释分式方程为什么可以在非零范围内去分母、根式方程为什么平方后要检查，以及分母含未知数的不等式为什么不能直接去分母。

## 本章要解决的问题

学完本章，面对基本方程与不等式，应当能够：

1. 说明方程两边可以进行哪些等价变形；
2. 解基本分式方程，并保留原分母条件；
3. 解基本根式方程，并排除平方后出现的增根；
4. 根据乘除式的正负决定不等号是否改变方向；
5. 用零点划分数轴，判断一次因式及其乘积的符号；
6. 把基本分式不等式转化为乘积不等式，并始终排除分母禁点。

## 六节怎样连接起来

### 方程线

方程部分先建立最基本的等式变形规则，再把第四章的分式、根式条件放进求解过程。

| 顺序 | 内容 | 本节核心 |
| --- | --- | --- |
| [01 方程变形](01_方程变形.md) | 等式两边同时加减、乘除 | 乘除式必须确定不为 $0$ |
| [02-1 分式方程](02-1_分式方程.md) | 原分母条件、去分母、检查所得的值 | 在分母非零的范围内去分母可以保持等价 |
| [02-2 根式方程](02-2_根式方程.md) | 根式条件、孤立根式、平方、检查 | 平方会隐藏正负差别，所得的值必须回到原方程检查 |

分式方程与根式方程没有合在同一篇里，因为它们的关键变形不同：去分母依靠一个确定非零的式子，平方则可能扩大原方程允许的范围。

### 不等式线

不等式部分先看基本变形，再从单个一次因式的正负走向乘积和分式的符号。

| 顺序 | 内容 | 本节核心 |
| --- | --- | --- |
| [03 不等式变形](03_不等式变形.md) | 加减规则、正数乘除、负数乘除 | 不等号方向由乘除式的符号决定 |
| [04 乘积不等式](04_乘积不等式.md) | 一次因式、零点分区、穿针引线、重复因式 | 用零点划分数轴并判断各区间的乘积符号 |
| [05 分式不等式](05_分式不等式.md) | 分母禁点、移项通分、分母平方 | 把商的符号转化为乘积的符号 |

一元二次不等式放在“乘积不等式”中理解：当二次式能够分解成两个一次因式时，它就是两个因式的乘积不等式。三个一次因式、首项系数和重复因式也沿用同一套符号判断。

整章的学习顺序可以概括为：

```text
第四章的条件控制
→ 方程的等价变形
→ 分式方程与根式方程中的条件检查
→ 不等式乘除变形中的正负判断
→ 一次因式的正负
→ 零点划分与乘积符号
→ 分式不等式中的商与禁点
```

## 本章与前后内容的边界

本章直接使用第三章的因式分解和第四章的分式、根式条件，但不重复讲解分式与根式的意义、化简和四则运算。

本章处理：

- 基本等式与不等式的等价变形；
- 能通过一次去分母求解的基本分式方程；
- 能通过一次平方继续求解的基本根式方程；
- 能分解为一次因式乘积的基本二次、三次和含重复因式的不等式；
- 能通分并转化为已学乘积形式的基本分式不等式。

需要多次平方的复杂根式方程、更复杂的高次多项式分解、不能化成已学因式的部分以及含参数不等式，留到高中后续内容中系统讨论。

本章最后要形成的稳定判断是：每次变形以前，先检查它依赖的条件；每次得到结果以后，再确认这些值或区间仍然满足原来的方程或不等式。
