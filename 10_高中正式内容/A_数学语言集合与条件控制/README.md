# A 数学语言、集合与条件控制

## 模块定位

A 系列是高中数学正式内容的入口，负责把“对象、范围、条件、推出关系和合法变形”说清楚。

内容顺序遵循下面的理解路径：

```text
确定研究对象与范围
→ 用命题和量词表达要求
→ 判断条件之间的推出方向
→ 掌握等式与不等式的合法变形
→ 用函数观点统一理解二次方程和二次不等式
```

本模块不展开复杂参数题、恒成立技巧或综合解题套路。这些内容需要后续函数知识，或者应当进入方法树。

## A-01 集合

1. `01_集合与元素.md`：集合研究什么，怎样判断属于关系。
2. `02_集合的表示.md`：列举法、描述法和图形语言怎样表示同一范围。
3. `03_空集与全集.md`：没有元素与当前讨论总范围的区别。
4. `04_集合的基本关系.md`：子集、真子集和集合相等。
5. `05_集合的基本运算.md`：交集、并集和补集对应的条件结构。

## A-02 常用逻辑用语

1. `01_命题与真假.md`：什么样的陈述能够判断真假。
2. `02_全称量词与存在量词.md`：所有对象与至少一个对象的不同要求。
3. `03_含量词命题的否定.md`：如何否定整个量词命题。

## A-03 充分条件、必要条件与充要条件

1. `01_充分条件与必要条件.md`：从推出方向判断充分与必要。
2. `02_充要条件.md`：双向推出与两个条件范围相同。

## A-04 不等关系与区间

1. `01_实数区间.md`：连续实数范围的边界和区间记号。
2. `02_等式的性质与等价变形.md`：哪些操作保持等价，哪些操作需要条件。
3. `03_不等式的性质.md`：运算何时保持或改变大小方向。
4. `04_基本不等式.md`：基本不等式的推导、范围和等号条件。
5. `05_基本不等式与最值.md`：由基本不等式得到可取得的最大值或最小值。

## A-05 一元二次方程与一元二次不等式

1. `01_方程的根与函数的零点.md`：根、零点和图象交点的关系。
2. `02_一元二次方程实根的个数.md`：判别式与实根个数。
3. `03_一元二次不等式的解集.md`：零点、开口方向和符号区间。
4. `04_函数方程与不等式的统一关系.md`：从函数值统一理解三个对象。
