# 初高中衔接方法树与练习树：停用说明

> **状态：暂不可用。**

原设计输入包生成于项目早期，当时方法树、练习树、节点 ID、知识映射和反馈规则尚未形成统一标准。为避免旧快照继续被当作正式设计依据，原内容已停止使用。

当前约束如下：

- 现有 `method_tree/` 与 `practice_tree/` 内容只作为历史草案保留；
- 现有节点 ID、知识映射、练习映射和反馈标签不得用于正式页面、学习进度或自动反馈；
- 首页和章节页面不提供正式的方法树、练习树入口；
- 后续应先统一课程范围、节点命名、依赖关系、练习层级和反馈规则，再逐步重建；
- 新体系建立前，不在旧结构上继续追加或局部修补。

原始长版输入包仍可通过 Git 历史查阅，但不再代表 DGOpenKS 当前的方法树与练习树设计。
