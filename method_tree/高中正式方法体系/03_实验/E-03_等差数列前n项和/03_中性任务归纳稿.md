## 1. 本轮只归纳任务，不归纳解法

本稿只从题面事实中归纳“给了什么对象、明确要求什么、答案表示什么”。它不写怎样解，不把公式代入或局部计算命名为方法，也不创建候选 ID、正式 ID、`U/M/S/E/P/Q`、关系边、验证计划或应试价值结论。

归纳遵守以下硬规则：

1. 只使用 40 个 `analysis_pool` 事实；5 个 `context_only` 和 2 个 `reserved_challenge` 不参与归纳、补证据或解决歧义。
2. 同一 `fact_id` 不拆分。复合母题只设一个主归属，其他任务组只能记“附带覆盖”，不能再次计数。
3. A—C 近重复块最多计一个材料单位；D 类关系按 `must_same_side` 或 `review_before_split` 约束后续材料分配。
4. “独立材料是否足够”只判断是否有资格进入下一轮候选设计审查，不是正式验证，不产生“高频、代表性、应试价值已验证”等结论。
5. 数学桥梁若不能由三篇核心稿直接支撑，材料暂停；不得用教材答案或本稿补写新的数学解释。

本稿使用“任务组 1—6”作为中性排版序号。它们不是方法名、题型名、候选身份或最终拆分数量。

## 2. 六个初步中性任务组

### 任务组 1：由等差数列基本量求指定和或缺失量

| 字段 | 中性归纳 |
| --- | --- |
| 输入对象 | 一个已声明为等差数列的有限前缀，以及 $a_1,a_n,d,n,S_n$ 中足以形成有限约束的一部分 |
| 显式目标 | 求题面指定的 $S_n$ 或一个或多个缺失基本量；目标包含 $n$ 时，求合法项数 |
| 输出含义 | 指定前缀的总和或缺失基本量的数值；若求项数，输出须是满足原条件的正整数解集合，并允许无合法解或不唯一 |
| 题面可见信号 | 五个基本量直接出现；“前多少项的和为……”；首项、末项、公差、项数或总和以表格或等式给出 |
| 任务不变量 | 所有量描述同一有限等差前缀；$n$ 是数列实际具有的正整数项数；所得值必须同时满足给定关系与定义域 |
| 范围与边界 | 同一多问题或表格不可拆票；只有满足原条件的正整数方程解才是合法项数；退化或信息不足时答案可能不唯一；只完成一次无选择的公式计算不自动构成独立完整任务 |
| 来源支撑 | 主归属：组 1 的 `RJ-EX-06`、`RJ-PR1-01`、`RJ-HW-01`、`BSD-HW-A07`；组 2 的 `RJ-PR1-02`、`BSD-PR1-02`。`RJ-PR1-02` 与组 1 存在 D 类反求项数桥，切分前复审 |
| 独立材料是否足够 | 当前无法判断。组 1 四题是一个 A—C 块且存在完全相同数据行；`BSD-PR1-02` 与 `BSD-EX-06` 也是近重复块。其余 D 类桥不自动扣票，但本组仍混合“直接求和、补多个基本量、反求项数”等目标；须先做粒度拆分，再按窄合同重新计数 |

主归属共 6 个事实。组 1 的同题各子问同时附带覆盖直接求和、补参数和反求项数，但不再分配到其他任务组。

主归属共 5 个事实；组 5 的 2 个事实在第 3 节单列暂停，不计入本组主归属。

### 任务组 3：确定有限选取部分的范围并求和

| 显式目标 | 确定被选有限部分的首项、末项或项数，并求其和 |
| 输出含义 | 被选子列或集合的准确范围、合法项数与总和 |

| 任务不变量 | 选择规则必须得到一个有限等差排列；闭区间项数要包含两端；严格与非严格边界不同；插入项不含原有两端；位置奇偶与数值奇偶不是同一件事 |
| 范围与边界 | 只问 $1+2+\cdots+n$ 或前 $n$ 个奇偶数的公式时，可能只是知识事实或局部计算；按位置拆成奇偶子列并由两组已知和反推原列信息，输入方向已经不同，不归入本组合同草图 |

| 显式目标 | 求情境总量；或由总量反求首阶段量、增量、对象数、离散时刻；复合情境还可能要求比较方案或判断总量是否满足需求 |

### 任务组 5：由前 $n$ 项和恢复原数列并判断整体结构

| 字段 | 中性归纳 |
| --- | --- |
| 输入对象 | 对 $n\in\mathbb N^*$ 给出的前 $n$ 项和表达式 $S_n$ |
| 显式目标 | 求原数列的项；题面要求时写前若干项或判断整个数列是否为等差数列 |
| 输出含义 | $a_1$ 与 $n\ge2$ 时 $a_n$ 的分段结果；若能统一，还要核验统一式在 $n=1$ 处成立；最后给出题面要求的整体结构结论 |
| 题面可见信号 | “已知前 $n$ 项和”“由 $S_n$ 求 $a_n$”“写前几项”“判断是否为等差数列” |
| 任务不变量 | $a_1=S_1$；$a_n=S_n-S_{n-1}$ 的适用范围是 $n\ge2$；当前定义没有 $S_0$；任何统一通项都必须同时满足 $n=1$；二次式常数项可能造成首项断裂 |
| 范围与边界 | 只求某一个相邻差可能是局部操作；不能把“二次型 $S_n$ 一定导出整个等差数列”当成无条件结论；题目若只给有限多个 $S_n$ 值，也不属于此输入合同 |
| 来源支撑 | 主归属：组 12 的 `RJ-BODY-09`、`RJ-PR2-02`、`BSD-HW-B06`；三篇核心稿直接支撑分段恢复与首项边界 |
| 独立材料是否足够 | 不足。三项是同一母型的一般探究、参数练习和跨版扩展实例，属于一个 A 类近重复块；任务族范围可以描述，但“恢复原项”与“继续判断整体结构”是否属于一个单一合同仍待类型与粒度审查 |

主归属共 3 个事实。

### 任务组 6：求正整数项数上的前缀和极值

| 字段 | 中性归纳 |
| --- | --- |
