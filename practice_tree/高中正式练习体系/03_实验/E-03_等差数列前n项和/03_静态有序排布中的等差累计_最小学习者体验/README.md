判定器是这 13 个步骤的局部适配器，只处理合同内的整数、选项、结构化结果含义、常见等价公式和完整逐项相加；它不是通用计算机代数系统。结果解释步骤把源合同中的累计范围、总量、单位和检查方式分开填写，避免用关键词猜测任意中文句子的正误。表述含糊或超出已覆盖结构时，原型宁可要求学习者改写清楚，也不据此生成正式掌握结论。

## 派生与交互计划

页面类型是“局部交互练习”，不是知识 HTML。学习路径固定为：

```text
当前题面与当前一步
→ 独立作答
→ 必要时逐层查看提示
→ 只反馈最早需要修正的一处
→ 当前步通过后由学习者主动进入下一步
→ 题目完成后原样显示完成解析
```

完整揭示只在当前步的三层提示全部释放后开放。学习者显式选择“查看完整解答”后，当前题直接进入 `answer_revealed` 终态，不再继续剩余小步。第 2、3 题的正确停止是成功终态，不使用失败样式。

浏览器只获得当前已释放的白名单字段。服务端先判断正确合同；未通过时再按诊断数组顺序检查，命中第一条后停止，只返回一条反馈。未来步骤、未释放提示、反馈数组、完成解析、内部键、关口、答案合同、来源锁和诊断名称都不进入浏览器响应。

## 设计方向

- 数学交互参考 Observable：题面、输入和反馈保持直接相邻。
- 产品界面参考 Linear：单一主路径、克制卡片、清楚的当前状态。
- 视觉沿用 OpenKS 的暖灰纸面、蓝色操作、绿色完成、琥珀色提示和红色修正。
- 不使用仪表盘、炫技动画、Canvas、3D、CDN 或第三方框架。
- 动效只用于短暂状态过渡，并支持 `prefers-reduced-motion`。

## 本地运行

需要 Node.js 24 或兼容版本，不需要安装依赖。

```bash
cd 'practice_tree/高中正式练习体系/03_实验/E-03_等差数列前n项和/03_静态有序排布中的等差累计_最小学习者体验'
node --test
node server.mjs
```

然后打开：

```text
http://127.0.0.1:4173/
```

可用 `node server.mjs --port 4174` 指定其他本地端口。服务只绑定 `127.0.0.1`，只显式提供本目录的三个前端文件和两项品牌资源；上级 JSON 没有静态访问路由。
